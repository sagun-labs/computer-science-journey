### ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🛡️ Division-by-zero protection
* 🔄 Repeat calculations

### 🧠 Concepts Used

`Variables` · `scanf()` · `printf()` · `switch` · `if/else` · `do...while` · `break`

### 📸 Example

```text
Enter the num1: 25
Enter the operation (+ - * /): *
Enter the num2: 4

25.00 * 4.00 = 100.00
```
